# 🎵 Kabett Music

Bem-vindo ao Kabett Music, um projeto desenvolvido para reunir informações sobre artistas, grupos musicais, álbuns, músicas e conteúdos relacionados ao universo da música.

O objetivo do site é oferecer uma experiência visual moderna e organizada, permitindo que os usuários explorem diferentes artistas e descubram informações de forma simples e agradável.

## ✨ Funcionalidades
- 🎤 Página de artistas
- 👥 Informações sobre integrantes de grupos
- 💿 Páginas de álbuns e singles
- 🔍 Sistema de pesquisa
- 🖼️ Galeria de imagens
- 🎵 Playlists incorporadas
- 📱 Layout responsivo

## 💻 Tecnologias utilizadas
- HTML5 – Estrutura do site
- CSS3 – Estilização e design
- JavaScript – Interatividade
- Git e GitHub – Controle de versão e hospedagem do projeto

## 📌 Objetivo do projeto

Este projeto foi criado para praticar e desenvolver habilidades em:

- Estruturação de páginas com HTML;
- Estilização avançada com CSS;
- Interatividade com JavaScript;
- Organização e documentação de projetos no GitHub.
